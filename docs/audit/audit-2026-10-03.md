# Repo-wide adversarial audit — 2026-10-03

Scope: the nine features shipped this cycle (PRs #32–#42 — interprocedural trace, MITRE
mapping, audit-evidence + drift, evidence pack, patch currency, transport content,
threat hunt, remediation roadmap, UEBA-lite) and their server surface. Validated on
synthetic fixtures only; real-RISE-export validation (P0) remains blocked ~2–3 months.

Method: three adversarial reviewers run in parallel — correctness/false-green,
charter/honesty, and security — each producing concrete findings, then **every finding
re-verified against the code** before acceptance. No finding was taken on trust.

## Result

- **Security — clean.** No SQL injection (every data value bound), no missing
  authorization/scope (all ten new endpoints authenticated + `auth.scope_for`), no
  HTML/output injection (the evidence pack escapes every interpolated value, including
  the attacker-influenced affected-objects), no user-controlled file path, no practical
  DoS.
- **Charter/honesty — strong.** No fabricated identifiers (all 7 CVE↔note bindings
  cross-checked), no percentages, no false "compliant"/"current", no live-monitoring
  claims, stdlib purity intact in `modules/`.
- **Correctness — no critical/high bug.** One genuinely false-green test and a handful
  of coverage/consistency gaps.

## Accepted / not changed (with reason)

- **Lens coverage self-signalling** (finding_classes / perceived_threats don't self-flag
  "not assessed" on empty input): by design — these are thin re-groupings; coverage is
  framed by the coverage/evidence-gaps screens and the domains roll-up.
- **`control_status` CLEAR when coverage is None**: mitigated — the real path
  (`/evidence`, `/drift`, the evidence pack) always passes `latest_coverage`; mirrors the
  frozen `nist_csf` recipe, so not diverged here.
- **`plan_for_system` zip-truncation caveat** and **`finding_classes` total-vs-counts on
  unknown severity**: pre-existing, currently harmless; out of this audit's change scope.
- **`totals.findings` sum-across-controls** in `control_status`: a per-control evidence
  volume by design, not a distinct-finding count.
- **LREV-PAT-002 "treat as compromise"**: conditional incident-response guidance, within
  the charter (pre-existing).

Net: 7 fixes (4 MED + 3 LOW), 0 regressions; the rest reasoned-and-accepted. Full suite
green on a pristine DB.
